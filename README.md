📱 QR Code Generator

A simple and interactive QR Code Generator built using HTML5, CSS3, JavaScript, and the QRCode.js Library.

This web application allows users to generate customized QR codes for any website URL by selecting the QR code size, foreground color, and background color. The generated QR code can also be downloaded instantly as an image.

The project demonstrates practical implementation of JavaScript DOM Manipulation, Event Handling, CSS Animations, and integration of the QRCode.js library for dynamic QR code generation.

⚙ Working Principle

1. User enters a website URL.
2. User selects the QR code size.
3. User chooses foreground and background colors.
4. JavaScript validates the input.
5. The loading spinner is displayed.
6. QRCode.js dynamically generates the QR code.
7. The loading spinner disappears after generation.
8. The generated QR code is displayed.
9. Users can download the QR code as an image.

---

🧠 How It Works

1. Enter a website URL.
2. Select the QR code size.
3. Choose QR code colors.
4. Click Generate QR Code.
5. QRCode.js creates the QR code.
6. Preview the generated QR code.
7. Download the QR code image.

---

🧪 Validation & Error Handling

- Displays an alert if the URL field is empty.
- Prevents QR code generation without valid input.
- Removes the previous QR code before generating a new one.
- Ensures only one QR code is displayed at a time.
